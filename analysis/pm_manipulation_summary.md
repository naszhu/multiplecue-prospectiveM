# PM manipulation check

**Verdict:** PM-cue engagement clearly works, but the predicted larger nonfocal than focal monitoring cost is not yet established.

![RT by phase and cue, subjects 17–42](fig/rt_median_by_phase_cue_all_subjects_p01_of_02_sub17-42.png)

This should show dual-cue slowing and PM-related slowing; dual-cue RTs are generally higher, but PM effects vary across participants, so the task works while the monitoring manipulation is mixed.

![RT by phase and cue, subjects 43–44](fig/rt_median_by_phase_cue_all_subjects_p02_of_02_sub43-44.png)

This should replicate the RT patterns; subject 44 slows under PM but subject 43 does not, so support for the monitoring manipulation remains mixed.

![Accuracy by phase and cue, subjects 17–42](fig/accuracy_by_phase_cue_all_subjects_p01_of_02_sub17-42.png)

This should detect PM-related impairment of the ongoing task; accuracy is mostly high across phases, so the PM task does not generally disrupt performance.

![Accuracy by phase and cue, subjects 43–44](fig/accuracy_by_phase_cue_all_subjects_p02_of_02_sub43-44.png)

This should confirm preserved ongoing-task performance; both participants remain highly accurate, so there is no meaningful accuracy cost.

![PM hit rate by subject](fig/pm_hit_rate_all_subjects.png)

This should confirm cue detection; hit rates are approximately 85–100% and far above the 20% criterion, so PM engagement clearly works.

![PM false-alarm rate by subject](fig/pm_false_alarm_all_subjects.png)

This should confirm response selectivity; false alarms are below 0.5%, so participants are not pressing the PM key indiscriminately.

![PM monitoring cost by subject](fig/pm_monitoring_cost_all_subjects.png)

This should show positive costs, especially for nonfocal PM; costs vary strongly in sign across participants, so the predicted manipulation is not consistent.

![Group PM engagement rates](fig/pm_manipulation_group_means_rates.png)

This should summarize PM engagement; near-ceiling hits and near-zero false alarms show that both cue types successfully elicit selective PM responses.

![Group mean monitoring cost](fig/pm_manipulation_group_means_cost.png)

This should show a larger positive nonfocal cost; the means are −6 ms focal and +5 ms nonfocal with large SEs, so the direction is suggestive but the manipulation is not confirmed.
